## INTRODUCTION

This is a asynchronous web scraper designed based on rest api from woocomerce of you're site from ikea to retrieve information from IKEA and store it locally in a csv file inside of you're current repo and email the result .

## REQUIREMENTS

Make sure that you have all of these installed on the device you want to run the program on:

- python 
- pip

## INSTALLATION

Use the package manager pip to install it. Type “pip install -r requirments.txt” into your terminal and it should download all the nassecery requirments. The main program is stored in the file “main.py” and can be run on any software capable of running Python3 code.
